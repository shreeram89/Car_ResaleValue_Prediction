# Car Resale Price Predictor
The repository contains the ml project that predicts the resale value of car based on the how km it driven, age, car model etc. 


Project Overview -
The Car Resale Price Predictor is an end-to-end Machine Learning web application designed to estimate the resale value of used cars. Using historic vehicle data, the project implements a robust data preprocessing pipeline and a Linear Regression model to predict prices based on several vehicle attributes. The application features a clean, interactive user interface built with Streamlit, allowing users to get real-time price valuations instantly.

Tech Stack -
• Language: Python
• Data Manipulation: Pandas, NumPy
• Machine Learning: Scikit-Learn
• Model Deployment: Streamlit
• Model Tracking/Saving: Joblib
